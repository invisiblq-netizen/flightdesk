Start or join a shared cockpit

Enter your name and choose a role. The host opens a new lobby; other pilots join with its seven-character code. A fresh code is generated for each flight, and previous sessions are not reopened automatically.

Host a lobby

Create a room and share its short code with your friend.

Join a lobby

The app automatically uses PeerJS Cloud to introduce the lobby participants; you do not need to run or sign up for a server. Notes, checklists and flight-plan data are sent directly between the PCs over WebRTC. A connection still depends on the signalling service and both networks allowing direct P2P traffic.
